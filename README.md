## ✨ Features (portfolio / main site)
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile
- **Dark/Light Theme**: Toggle between themes with persistent preference
- **Interactive Animations**: Smooth scroll effects and animated skill bars
- **Accessibility**: ARIA labels, keyboard navigation, and skip links
- **Performance**: Lightweight vanilla JavaScript, no frameworks

## Run locally
```bash
npm start
```
Then open **http://localhost:3690** in your browser. The home page links to Course Work; from there you can open any session demo.

You can also open `index.html` directly in your browser.

## GitHub Pages
1. Repo → **Settings** → **Pages**.
2. Set **Source** to **GitHub Actions**.
3. Pushes to `main` deploy automatically. Live URL: `https://vshah513.github.io/oim3690/`.
