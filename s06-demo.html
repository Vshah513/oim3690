Session 6: Semantic HTML — the “better version” of marking up a site header and navigation.

Better version (from slides)

<header> <h1>My Site</h1> <nav> <a href="/">Home</a> </nav> </header>

What's better?

  • Clear structure — Header and nav are explicitly defined, not just divs.
  • Screen readers understand it — Assistive tech can identify landmarks and navigation.
  • Proper heading hierarchy — One <h1> for the site title sets the document outline.
