What we learned

  • External CSS — <link rel="stylesheet" href="..."> loads a separate .css file so you can reuse styles across pages.
  • Inline <style> — Rules in the document apply only to that page; good for one-off overrides or demos.
  • Commenting out CSS — Use /* ... */ to turn off a rule without deleting it (handy for debugging).
  • Images — Use descriptive alt text (e.g. “A picture of Babson Campus”) for accessibility; width controls size without distorting aspect ratio when used alone.
Best practice: Prefer one main external stylesheet (e.g. styles.css) for layout, typography, and colors. Use inline <style> only for page-specific tweaks or when you’re experimenting. Add rel="noreferrer" to links that open in a new tab (target="_blank") for security and privacy.
