Session 9 Demo — Google Fonts & CSS Selectors

Loading web fonts with preconnect, and targeting elements with classes, IDs, and multiple classes.

From class: Fonts + class and id selectors

1. Google Fonts in the <head> — Preconnect speeds up font loading; then we load the font stylesheet:

<link rel="preconnect" href="https://fonts.googleapis.com" /> <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin /> <link href="https://fonts.googleapis.com/css2?family=Libertinus+Keyboard&family=Oswald:wght@200..700&display=swap" rel="stylesheet" />

2. Inline <style> — Element selectors (h1, p) plus classes and IDs in the HTML:

h1 { color: blue; } p { color: purple; } /* In HTML: class="yellow", id="second-paragraph", class="julissa yellow" */

External styles.css would define .yellow (e.g. color or background). In the live demo below, .yellow is yellow text, #second-paragraph has a left border, and .julissa.yellow uses both classes.

What we learned

  • Preconnect — rel="preconnect" tells the browser to connect to fonts.googleapis.com and fonts.gstatic.com early, so font files load faster.
  • display=swap — Shows fallback text immediately, then swaps in the custom font when it loads (avoids invisible text).
  • Classes (e.g. .yellow) — Reusable; one class can be on many elements. Use for repeated styling.
  • IDs (e.g. #second-paragraph) — Unique per page. Use for one-off styling or JavaScript hooks. Higher specificity than classes.
  • Multiple classes — class="julissa yellow" means the element matches both .julissa and .yellow; you can combine rules (e.g. .julissa.yellow targets only elements that have both).
