What we learned

  • flex-direction — row (default) or column sets the main axis. Items flow along that axis.
  • justify-content — Aligns items along the main axis: center, space-between, space-around, flex-start, flex-end.
  • align-items — Aligns items on the cross axis. Use with min-height on the container to see vertical centering.
  • flex-wrap — wrap lets items move to the next line when there isn’t enough space. Use with fixed or min widths on items (e.g. flex: 0 0 150px).
  • flex (grow/shrink/basis) — flex: 1 lets items share space equally; flex: 2 on one item makes it take twice as much space as flex: 1 items.
  • gap — Adds space between flex items without margins. Cleaner than using margin on each item.
  • Centering a single item — justify-content: center + align-items: center on the flex container centers the child both horizontally and vertically.
