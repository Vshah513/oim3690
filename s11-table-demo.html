Session 11 — Table Demo

Semantic HTML tables with <thead>, <tbody>, <th>, and <td>. Use tables for tabular data (rosters, schedules, comparisons), not for page layout.

Student Roster

Sample student roster from class
ID Name Major GPA Year
001 Sarah Johnson Computer Science 3.8 Junior
002 Marcus Chen Business 3.6 Senior
003 Emily Rodriguez Engineering 3.9 Sophomore
004 Andrew Kim Data Science 3.7 Junior
005 Jessica Lee Marketing 3.5 Senior

HTML structure from class

<table> <thead> <tr><th>ID</th><th>Name</th> ... </thead> <tbody> <tr><td>001</td><td>Sarah Johnson</td> ... </tbody> </table>

What we learned

  • <table> — Wraps the whole table. Use for tabular data (rows and columns that relate to each other).
  • <thead> — Header section. Contains one or more <tr> with <th> cells for column (or row) headers.
  • <tbody> — Body section. Contains <tr> rows with <td> data cells.
  • <th> — Header cell (bold by default). Use scope="col" for column headers or scope="row" for row headers so screen readers can announce the table correctly.
  • <td> — Data cell. One per column per row.
  • <caption> — Optional. Short title for the table; helps accessibility and is read by screen readers.
Best practice: Avoid border="1" on the <table> tag. Use CSS (border, border-collapse: collapse) to style the table so you can control spacing, colors, and responsiveness. Use tables for data only — use Flexbox or Grid for page layout.
